# 审计日志

查看控制台**写操作审计**：谁、在哪个模块、对哪条数据、做了新增 / 修改 / 删除 / 回滚 / 授权。数据来自 `HUB_AUTH_AUDIT_LOG`，由鉴权中间件与业务在写接口成功后写入。本页只读，不能改或删记录。

---

## 概述

**审计日志**面向安全管理员与合规排查，用来：

- **追溯变更**：定位某次用户、角色、资源、路由等配置是谁改的。
- **核对授权**：筛选动作「授权」，查看角色资源或用户角色的授予记录。
- **区分流量日志**：网关访问日志在「网关管理 → 网关日志管理」；本页只记管理面操作。

审计在写接口成功后落库。查询本页本身不写审计。

---

## 访问入口

侧栏 **系统设置** → **审计日志**。

已有库需执行对应库的 `patch_auth_resource_20260820_hub0004.sql`，并确认已有 `HUB_AUTH_AUDIT_LOG`。超级管理员与只读角色会补上本模块授权；其他角色在「角色管理」中勾选 `hub0004`。

---

## 使用流程

1. 进入页面后默认加载**最近 7 天**的记录。
2. 按动作、模块、操作人缩小范围；需要目标名称、资源编码、客户端 IP 时点 **更多条件**。
3. 点 **查询**。清空时间范围可查全部历史（数据量大时可能较慢）。
4. 行上 **右键 → 查看详情**，核对目标 ID、请求路径与补充说明。

## 筛选条件

| 条件 | 说明 |
|------|------|
| 时间范围 | 按记录创建时间过滤；默认最近 7 天，可改快捷项或自定义。 |
| 动作 | 新增、修改、删除、回滚、授权。 |
| 模块 | 产生该操作的控制台模块（如用户管理 `hub0002`）。 |
| 操作人 | 按用户名模糊匹配。 |
| 结果（更多） | 成功或失败。 |
| 目标类型 / 名称 / ID（更多） | 被操作对象，如用户、角色、路由。 |
| 资源编码（更多） | 按钮或接口资源码，如 `hub0002:edit`。 |
| 用户 ID / 客户端 IP（更多） | 精确用户 ID；IP 支持模糊匹配。 |

---

## 列表字段

| 列 | 说明 |
|----|------|
| 操作时间 | 审计写入时间。 |
| 操作人 | 当时登录用户名。 |
| 动作 | 新增 / 修改 / 删除 / 回滚 / 授权。 |
| 模块 | 模块编码及名称。 |
| 目标类型 / 名称 / ID | 被改对象。中间件兜底时类型可能为接口。 |
| 资源编码 | 触发该次写操作的权限码。 |
| 结果 | 成功或失败。当前写入以成功为主。 |
| 客户端 IP / 请求路径 | 来源地址与管理端 API 路径。 |

---

## 详情

详情按基本信息、操作对象、请求信息分组。补充说明若为 JSON 会格式化展示，否则按原文。审计记录不可修改、不可删除。

---

## 权限

本模块只授查询类按钮：`hub0004:view`、`hub0004:search`、`hub0004:reset`。有模块权限即可调列表与详情接口。看不到菜单时，请管理员在角色中授予 `hub0004`。

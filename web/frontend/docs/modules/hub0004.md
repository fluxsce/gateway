# 审计日志

查看控制台**写操作审计**：谁、在哪个模块、对哪条数据、做了新增 / 修改 / 删除 / 回滚 / 授权 / 导出 / 登录 / 踢会话。数据来自 `HUB_AUTH_AUDIT_LOG`。业务模块 `SetEvent` 放入对象后，由全局审计中间件在请求结束时落库。鉴权中间件不参与。本页不能改或删记录，可按条件导出 CSV。

---

## 概述

**审计日志**面向安全管理员与合规排查，用来：

- **追溯变更**：定位某次用户、角色、资源、路由等配置是谁改的。
- **核对授权**：筛选动作「授权」，查看角色资源或用户角色的授予记录。
- **核对登录**：筛选「登录 / 登录失败 / 踢会话」。验证码、单次密码或账号错误不记审计（在登录日志里）；审计里的登录失败只表示账号进入冷却。
- **区分流量日志**：网关访问日志在「网关管理 → 网关日志管理」；本页只记管理面操作。

写接口成功记 `result=Y`，业务失败或按钮无权限记 `result=N`。查询本页本身不写审计；**导出**会记一条 `EXPORT`。

---

## 访问入口

侧栏 **系统设置** → **审计日志**。

已有库需执行对应库的 `patch_auth_resource_20260820_hub0004.sql`，并确认已有 `HUB_AUTH_AUDIT_LOG`。导出按钮另执行 `patch_auth_resource_20260820_hub0004_export.sql`。超级管理员与只读角色会补上本模块授权；其他角色在「角色管理」中勾选 `hub0004`（导出需 `hub0004:export`）。

---

## 使用流程

1. 进入页面后默认加载**最近 7 天**的记录。
2. 按动作、模块、操作人缩小范围；需要目标名称、资源编码、客户端 IP 时点 **更多条件**。
3. 点 **查询**。清空时间范围可查全部历史（数据量大时可能较慢）。
4. 行上 **右键 → 查看详情**，核对目标 ID、请求路径与补充说明。
5. 点 **导出** 下载当前筛选条件下最多 10000 条 CSV。

---

## 筛选条件

| 条件 | 说明 |
|------|------|
| 时间范围 | 按记录创建时间过滤；默认最近 7 天，可改快捷项或自定义。 |
| 动作 | 新增、修改、删除、回滚、授权、导出、登录、登录失败、踢会话。 |
| 模块 | 产生该操作的控制台模块（如用户管理 `hub0002`）。 |
| 操作人 | 按用户名模糊匹配。 |
| 结果（更多） | 成功或失败。 |
| 目标类型 / 名称 / ID（更多） | 被操作对象，如用户、角色、路由。 |
| 资源编码（更多） | 按钮或接口资源码，如 `hub0002:edit`。 |
| 用户 ID / 客户端 IP（更多） | 精确用户 ID；IP 支持模糊匹配。 |

## 列表字段

| 列 | 说明 |
|----|------|
| 操作时间 | 审计写入时间。 |
| 操作人 | 当时登录用户名。 |
| 动作 | 新增 / 修改 / 删除 / 回滚 / 授权 / 导出 / 登录 / 踢会话。 |
| 模块 | 模块编码及名称。 |
| 目标类型 / 名称 / ID | 被改对象，由业务 `SetEvent` 填写。 |
| 资源编码 | 触发该次写操作的权限码。 |
| 结果 | 成功或失败。 |
| 客户端 IP / 请求路径 | 来源地址与管理端 API 路径。 |

---

## 详情

详情按基本信息、操作对象、请求信息分组。补充说明来自业务 `SetEvent`；失败时改为错误信息。若为 JSON 会格式化展示。口令、验证码等敏感字段不会写入。审计记录不可修改、不可删除。

---

## 权限

本模块按钮：`hub0004:view`、`hub0004:search`、`hub0004:reset`、`hub0004:export`。有模块权限即可调列表与详情接口；导出需 `hub0004:export`。看不到菜单时，请管理员在角色中授予 `hub0004`。

# 开发指南

从源码编译、本地启动。只想试用请用根目录 [README.md](../../README.md) 的 Docker 或安装包，不必走本文。

当前版本示例：**3.2.8**。

---

## 环境

| 组件 | 要求 |
|------|------|
| Go | 1.24+（`go.mod` 声明 `go 1.24.0`） |
| C 编译器 | 必须。SQLite 使用 `github.com/mattn/go-sqlite3`，需要 CGO |
| Node.js | 18+，仅改控制台时需要 |
| pnpm | 前端仓库使用 pnpm |
| Git | 克隆源码 |

Windows 安装 [TDM-GCC](https://jmeubank.github.io/tdm-gcc/download/)（推荐 `tdm64-gcc-10.3.0-2.exe`），装完**重新打开终端**，确认 `gcc --version`。Linux：`sudo apt-get install build-essential` 或对应发行版的 gcc。macOS：`xcode-select --install`。

国内 Go 代理：

```bash
go env -w GOPROXY=https://goproxy.cn,direct
go env -w GOSUMDB=sum.golang.google.cn
```

Oracle Instant Client **不是**默认依赖。只有编译/运行带 Oracle 的二进制时才需要，见文末可选章节。

## 获取源码

```bash
git clone https://github.com/fluxsce/gateway.git
cd gateway
go mod download
```

主要目录：

```
cmd/app/            进程入口
cmd/starter/        启动与系统服务封装
configs/            运行配置（直接改这些文件，不要另写一份旧格式）
internal/           网关、隧道、注册中心等内部实现
pkg/                可复用包
web/frontend/       Vue 控制台
scripts/db/         按 mysql / sqlite / oracle 分目录的 SQL
scripts/build/      官方打包脚本
scripts/deploy/     系统服务安装脚本
scripts/docker/     镜像与 Compose
```

## 数据库

默认配置（`configs/database.yaml`）：

- `database.default: sqlite_main`
- 库文件：`./scripts/data/gateway.db`
- `enable_script_initialization: true`：启动时执行 `scripts/db` 下对应驱动的脚本

一般**不必**手工导入 SQL。若要手动执行，必须在该库种目录内运行（`init.sql` 使用相对路径）：

```bash
# SQLite
cd scripts/db/sqlite
sqlite3 ../../data/gateway.db < init.sql

# MySQL（先建库）
mysql -u root -p -e "CREATE DATABASE gateway CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
cd scripts/db/mysql
mysql -u root -p gateway < init.sql
```

不存在 `scripts/db/mysql.sql` 或 `frp_tunnel_management.sql`。

切到 MySQL 时改现有 YAML，不要换成 `type/host` 结构：

```yaml
database:
  default: mysql
  connections:
    mysql:
      driver: mysql
      enabled: true
      connection:
        host: 127.0.0.1
        port: 3306
        username: root
        password: "your_password"
        database: gateway
    sqlite_main:
      enabled: false
```

## 启动

### 后端

```bash
go run cmd/app/main.go --config ./configs
```

成功后：

- 网关：http://localhost:8080
- 控制台 API / 健康检查：http://localhost:12003/health
- 控制台路径前缀：`/gatewayweb`（见 `configs/web.yaml` 的 `frontend.prefix`）

### 前端

`web/frontend/dist` 不进 Git。开发时另开终端：

```bash
cd web/frontend
pnpm install
pnpm run dev:vite
```

Vite 把 API 代理到 `http://127.0.0.1:12003`（可用环境变量 `VITE_API_PROXY_TARGET` 覆盖）。

要让网关进程直接托管控制台：

```bash
cd web/frontend
pnpm run build
```

然后重启 `go run`，浏览器打开 http://localhost:12003/gatewayweb 。

默认账号 `admin` / `123456`，登录后立刻改掉。

控制台里还没有转发规则。按 [第一条路由](./09-第一条路由.md) 建实例、服务、前缀路由并**重载**，再用 `curl http://localhost:8080/...` 验证。

验证：

```bash
curl http://localhost:12003/health
# 预期包含 "status":"ok"
```

网关端口 `8080` 没有 `/health`。

## 配置改哪里

只改仓库里的 YAML，字段以文件注释为准。

| 文件 | 常见项 |
|------|--------|
| `configs/app.yaml` | 模块开关、版本字段、加密密钥 |
| `configs/database.yaml` | 默认连接、连接池、脚本初始化 |
| `configs/gateway.yaml` | `base.listen`（默认 `:8080`） |
| `configs/web.yaml` | `port`（默认 `12003`）、`frontend.prefix` |
| `configs/logger.yaml` | 级别与输出 |

## 官方构建脚本

输出目录：`dist/gateway/`（可执行文件、`configs/`、`web/`、`scripts/db`）。**必须传版本号**。默认 **不含 Oracle**（`no_oracle`）。

```cmd
cd scripts\build
build-win10.cmd --version=3.2.8
build-win10.cmd --oracle --version=3.2.8
```

```bash
cd scripts/build
./build-centos7.sh --version=3.2.8
./build-centos7.sh --oracle --version=3.2.8
```

Windows Server 2008 兼容且需要 Oracle 时用 `scripts/build/build-win2008-oracle.cmd`。

仅本地调试也可以：

```bash
go build -o bin/gateway cmd/app/main.go
```

该产物未做发布优化，不要当生产包。

## 可选：Oracle

仅当 `build-*.cmd/--oracle` 或运行 `*-oracle-*` 包时需要。Oracle Instant Client 受许可限制，不能打进安装包；Docker Oracle 镜像已内置客户端。

Linux 需要 Basic + SDK（编译）或仅 Basic（运行预编译包），设置 `ORACLE_HOME` 与 `LD_LIBRARY_PATH`。下载页：[Instant Client](https://www.oracle.com/database/technologies/instant-client/linux-x86-64-downloads.html)（需接受许可）。systemd 不会继承用户的 `LD_LIBRARY_PATH`，服务文件里要显式写出，安装脚本会尝试检测。

Windows：解压 Instant Client 后把它加入 `PATH`，或运行 `scripts/build/setup-oracle-env.cmd`。

`configs/database.yaml` 中启用 `oracle_main`，并把 `database.default` 改为 `oracle_main`。

## 常见错误

| 现象 | 处理 |
|------|------|
| `cgo: C compiler "gcc" not found` | 安装 gcc，重开终端 |
| `bind: address already in use` | 改 `gateway.yaml` / `web.yaml` 端口，或结束占用进程 |
| 控制台空白 / 404 | 未构建 `web/frontend/dist`，见上文前端步骤 |
| 初始化数据库失败 | 查 `database.yaml`、文件权限、`scripts/db` 是否与进程工作目录一致 |

更多见 [FAQ](../faq.md)。

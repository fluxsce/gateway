# 安装部署

用官方安装包在机器上运行。Docker / Kubernetes 见 [容器化部署](./04-容器化部署.md)。从源码打包见 [开发指南](./02-快速开始.md)。

下文以 **3.2.7** 和安装目录 `/opt/gateway` 为例，按实际路径替换。

---

## 环境

| 项 | 最低 | 建议 |
|----|------|------|
| 系统 | Linux / Windows / macOS | 64 位 |
| CPU / 内存 / 磁盘 | 1 核 / 256MB / 10GB | 2 核+ / 512MB+ / 20GB+ |
| 数据库 | 默认 SQLite | 生产可用 MySQL 5.7+/8.0 或 Oracle 11g+ |
| 可选 | Redis 6+（缓存/分布式限流）、ClickHouse 21+（日志分析） |

标准安装包已链接 SQLite/MySQL/ClickHouse，**不必**在本机装 gcc。文件名含 `oracle` 的包需要自行安装 Oracle Instant Client（许可不允许随包分发）。Go 1.24 要求 Linux kernel ≥ 3.17；CentOS 7 默认 3.10 可能无法运行二进制，可改用 Docker 镜像。

---

## 下载

打开 [Releases](https://github.com/fluxsce/gateway/releases)，按平台取包。CI 产物名称：

| 文件 | 说明 |
|------|------|
| `gateway-linux-amd64-{version}.tar.gz` | Linux amd64，无 Oracle |
| `gateway-linux-arm64-{version}.tar.gz` | Linux arm64，无 Oracle |
| `gateway-linux-amd64-oracle-{version}.tar.gz` | Linux amd64 + Oracle，不含 Instant Client |
| `gateway-windows-amd64-{version}.zip` | Windows amd64，无 Oracle |
| `gateway-windows-amd64-oracle-{version}.zip` | Windows amd64 + Oracle，不含 Instant Client |

没有 Linux arm64 Oracle 包，也没有 Windows arm64 包。归档根目录是 `gateway/`。

```bash
wget https://github.com/fluxsce/gateway/releases/download/v3.2.7/gateway-linux-amd64-3.2.7.tar.gz
sudo tar -xzf gateway-linux-amd64-3.2.7.tar.gz -C /opt
cd /opt/gateway
```

Windows：解压 zip 到例如 `C:\gateway`。

不要使用旧文档里的 `gateway-linux-amd64.tar.gz`（无版本号）或 `v2.0.1` 路径，那些地址会 404。

---

## 目录

解压后至少包含：

```
gateway/
├── gateway                 # Windows 为 gateway.exe
├── configs/
│   ├── app.yaml
│   ├── database.yaml
│   ├── gateway.yaml
│   ├── logger.yaml
│   └── web.yaml
├── web/static/
├── web/frontend/dist/
├── scripts/db/             # mysql / sqlite / oracle
└── scripts/deploy/         # 系统服务脚本（若包内带了）
```

SQLite 文件默认写在 `scripts/data/gateway.db`，首次启动自动创建。`enable_script_initialization` 为 true 时会跑 `scripts/db`。

---

## 配置

默认即可用 SQLite 启动。改库时编辑 `configs/database.yaml`：把 `database.default` 改成 `mysql` 或 `oracle_main`，打开对应 `connections.*`，关掉 `sqlite_main`。完整字段在该文件里，不要写成：

```yaml
# 错误：当前配置不是这种结构
database:
  type: mysql
  host: localhost
```

生产至少修改：

- `configs/web.yaml`：`jwt_secret`、`encryption_key`
- `configs/app.yaml`：`encryption_key`
- 控制台默认用户 `admin` / `123456`

## 启动

### 直接运行

```bash
cd /opt/gateway
./gateway --config ./configs
```

```cmd
cd C:\gateway
gateway.exe --config .\configs
```

### 系统服务（生产建议）

Linux：

```bash
cd /opt/gateway
sudo scripts/deploy/install-service-linux.sh
sudo systemctl start gateway
sudo systemctl status gateway
```

Windows：

```cmd
cd C:\gateway
scripts\deploy\install-service.cmd
sc start Gateway
sc query Gateway
```

Oracle 版 Windows 可加参数：`scripts\deploy\install-service.cmd oracle`。Linux 上 Oracle 动态库路径必须写进 systemd 环境，安装脚本会尝试检测 `ORACLE_HOME`。

## 验证

```bash
curl http://localhost:12003/health
```

浏览器：http://localhost:12003/gatewayweb  

网关业务口：http://localhost:8080  

健康检查只在 **12003**。Compose 映射端口见 [容器化部署](./04-容器化部署.md)。

## 升级

先停服务，备份 `configs/database.yaml`（以及你改过的其它 YAML），再解压覆盖，最后拷回配置。

```bash
sudo systemctl stop gateway
sudo cp /opt/gateway/configs/database.yaml /tmp/database.yaml.bak
sudo tar -xzf gateway-linux-amd64-*.tar.gz -C /opt
sudo cp /tmp/database.yaml.bak /opt/gateway/configs/database.yaml
sudo systemctl start gateway
```

库表变更以该版本 [CHANGELOG.md](../../CHANGELOG.md) 为准，已有库可能需要执行 `scripts/db/*/patch_*.sql`。

## 自行编译

```bash
cd scripts/build
./build-centos7.sh --version=3.2.7          # 默认无 Oracle
./build-centos7.sh --oracle --version=3.2.7
```

产物在 `dist/gateway/`，拷到 `/opt/gateway` 后 `chmod +x /opt/gateway/gateway`（权限加在可执行文件上，不是目录）。细节见 [开发指南](./02-快速开始.md#官方构建脚本)。

# 容器化部署

镜像与 tag 由 GitHub Actions 推送，说明见 [.github/CI.md](../../.github/CI.md)。当前示例版本 **3.3.0**。

没有 Docker Hub 上的 `datahub-images/gateway`。请用：

| 仓库 | 镜像 |
|------|------|
| GitHub GHCR | `ghcr.io/fluxsce/gateway` |
| 阿里云 ACR | `crpi-25xt72cd1prwdj5s.cn-hangzhou.personal.cr.aliyuncs.com/datahub-images/gateway` |

常用 tag：`3.3.0`（amd64+arm64 清单）、`3.3.0-amd64`、`3.3.0-arm64`、`3.3.0-oracle`（仅 amd64，内置 Instant Client）、`latest`（仅 git tag 发版时打）。

## Docker：单容器试用

镜像内已有 `configs/`、`scripts/db/`、`web/frontend/dist`，默认 SQLite。

```bash
docker pull ghcr.io/fluxsce/gateway:3.3.0

docker run -d --name gateway \
  -p 8080:8080 \
  -p 12003:12003 \
  ghcr.io/fluxsce/gateway:3.3.0
```

- 控制台：http://localhost:12003/gatewayweb （`admin` / `123456`）
- 网关：http://localhost:8080
- 健康检查：`curl http://localhost:12003/health`

国内：

```bash
docker pull crpi-25xt72cd1prwdj5s.cn-hangzhou.personal.cr.aliyuncs.com/datahub-images/gateway:3.3.0
```

个人版 ACR 通常要先 `docker login`。

挂载自己的配置与日志（只读配置）：

```bash
docker run -d --name gateway \
  -p 8080:8080 \
  -p 12003:12003 \
  -v /opt/gateway/configs:/home/gateway/configs:ro \
  -v /opt/gateway/logs:/home/gateway/logs \
  ghcr.io/fluxsce/gateway:3.3.0
```

容器工作目录是 `/home/gateway`，入口：`/home/gateway/gateway --config /home/gateway/configs`。

## Docker Compose（MySQL + Redis）

文件：`scripts/docker/docker-compose.yaml`。为避开宿主机常用端口，映射为：

| 服务 | 容器内 | 宿主机 |
|------|--------|--------|
| 网关 | 8080 | **18280** |
| 控制台 | 12003 | **12203** |
| 隧道 | 7000 | 17000 |
| MySQL | 3306 | 13306 |
| Redis | 6379 | 16379 |

仓库自带的 `configs/database.yaml` 默认是 SQLite。要用 Compose 里的 MySQL，先改该文件：

```yaml
database:
  default: mysql
  connections:
    mysql:
      driver: mysql
      enabled: true
      connection:
        host: mysql
        port: 3306
        username: gateway
        password: gateway123
        database: gateway
    sqlite_main:
      enabled: false
```

`host` 必须是 Compose 服务名 `mysql`，不是 `localhost`。表结构由进程启动时的 `enable_script_initialization` 创建，不要再挂载已删除的 `frp_tunnel_management.sql`。

```bash
cd scripts/docker
docker compose up -d
docker compose ps
docker compose logs -f gateway
```

访问：http://localhost:12203/gatewayweb 、http://localhost:18280

```bash
docker compose stop
docker compose down        # 保留数据卷
docker compose down -v     # 连数据一起删
```

镜像默认 `ghcr.io/fluxsce/gateway:3.3.0`。改 ACR 时编辑 compose 的 `image:` 字段。

## Kubernetes

前置：集群 1.19+、kubectl、集群内可访问的 MySQL（或改配置用 SQLite 空目录，不推荐多副本）。

```bash
cd scripts/k8s
# 按环境改 deployment.yaml 的 image、replicas、namespace
bash deploy.sh install
bash deploy.sh status
```

默认镜像为阿里云 ACR `.../datahub-images/gateway:3.3.0`。国际环境可改为 `ghcr.io/fluxsce/gateway:3.3.0`。

ConfigMap 来自 `configs/`。其中 `database.yaml` 必须改成集群内 MySQL 地址，结构与上文 Compose 相同（`connections.mysql.connection.host`），不是 `database.type`。

卸载：`bash deploy.sh uninstall`。

## 自行构建镜像

发版流水线**不调用** `scripts/docker/build.sh`。本地构建：

```bash
cd scripts/docker
bash build.sh --type standard    # tag: {version}
bash build.sh --type oracle      # tag: {version}-oracle
```
